# 日常・脈搏

給閒置手機與面板的每日資訊頁。

**[開啟日看板](https://sink6985757-web.github.io/daily-pulse-panel/)**

台灣時間、新竹市東區天氣、25／5 分鐘番茄鐘、字根字首學習、農民曆、每日易經與生活節奏建議。手機橫直向輪播、大面板並排，可暫停閱讀。按「全螢幕時鐘 ⛶」可用大字顯示日期、時間與溫度；手機橫向及橫向螢幕採左側時鐘、右側天氣，按「返回日看板 ×」回到原畫面。

## 使用

用 Safari／瀏覽器開啟上方網址；iPhone 可從分享選單加入主畫面。按「保持亮屏」嘗試常亮；不支援時依畫面提示調整系統自動鎖定。iPhone 8 實機與長時間常亮尚需使用者確認。

`index.html` 與 `daily-panel.html` 是相同的獨立 HTML；可下載後在支援本機網頁執行的瀏覽器開啟。iOS 檔案預覽不保證完整執行；網址版沒有 Service Worker，離線重新載入取決於快取。天氣需要網路。

## 資料

- 台灣 UTC+08:00；裝置本身仍須自動校時。
- 天氣：[Open-Meteo](https://open-meteo.com/) 模型預報，依 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 標示來源，每 30 分鐘更新。新竹市東區使用代表座標，並非即時測站實測。
- 農民曆：[好日網](https://www.goodaytw.com/)，內建 2026-01-01 至 2027-12-31 快照；每筆有來源日期與 URL。超出範圍顯示待更新；供民俗文化參考。
- 字根課程、每日主題與易經內容由專案成品提供；本次已確認公開範圍。程式與資料的權利分別歸其權利人，本 repository 不另授予第三方內容的再散布授權。

這個 repository 僅保存網站成品。更新兩份 HTML 時應使用同一份已驗證產物，保留來源標示；GitHub Pages 從 main 根目錄發布。
